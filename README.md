# Market Data Engine

A self-study project for practicing arrays and data management in Python. It works through small exercises on a mock series of daily closing prices:

- **Max profit** — find the best single buy/sell pair from a list of prices.
- **Moving average** — compute a k-day sliding window average.
- **Missing days** — detect gaps in a sequence of logged trading days.

This code isn't meant for production use — it's a sandbox for building comfort with list operations, sliding windows, and set-based lookups in Python.
